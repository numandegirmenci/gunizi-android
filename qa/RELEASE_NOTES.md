Belge İzi Android test sürümü.

- Belgeyi taradıktan sonra otomatik Türkçe metin tanıma.
- Orijinal belgeyi koruyan Otomatik, Canlı Renk ve Siyah-Beyaz geliştirme.
- PDF oluşturma, metin düzenleme, imza ve kaşe araçları.
- Yeni sürekli entegrasyon: JVM regresyon testleri, Python kalite testi,
  sentetik Türkçe belge arşivi, Android derleme ve lint denetimi.
- APK doğrudan GitHub Releases üzerinden indirilebilir.

Bu, gerçek cihazda görüntü kalitesi ve OCR doğruluğu henüz tam doğrulanmamış
test sürümüdür. Test APK'lerinin debug imzaları değişebileceğinden, mevcut
uygulamayı silmeden önce belgelerinizi yedekleyin. Sabit imzalı sürüm yalnızca
\`BELGEIZI_*\` imzalama sırları güvenle yapılandırıldıktan sonra üretilir.

Gün İzi ses kayıt uygulaması bu sürümün parçası değildir.
